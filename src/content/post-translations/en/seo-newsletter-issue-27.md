<h2 id="toc-1">Starting from March this year, content that only appears on the desktop version will not be indexed</h2>
<p>in previous<a class="rank-math-link" href="./seo-newsletter-issue-19.html#toc-1">Newsletter</a>has said that Mobile First Indexing will be launched in March. By then, all websites will have their mobile version as the main version, and content that only appears on the desktop version will not be indexed.</p>
<figure class="wp-block-image size-large"><img alt="Illustration for SEO e-Newsletter Issue 27 – 2021.02.16~2021.02.28" decoding="async" height="332" loading="lazy" src="./wp-content/uploads/2020/11/google-%E7%A7%BB%E5%8B%95%E5%84%AA%E5%85%88.png" width="800"/><figcaption>Screenshot of John Mueller’s speech in October 2020</figcaption></figure>
<p>It is recommended that you find time to check in the near future to ensure that the content on the desktop and mobile versions are consistent. Can be used for small websites<a class="rank-math-link" href="https://technicalseo.com/tools/mobile-first-index/">this tool</a>Check important pages. Large websites can rely on Screaming Frog to compare User-Agent crawling results for desktop and mobile phones.</p>
<p>The key points of inspection basically include: title, description, # of links, # of images (alt tag), indexability, structured data...etc.</p>

<h2 id="toc-7">[Official article] How to provide more accurate product information</h2>
<p>In this article, Google said that they rely on identifiers to identify products. Commonly used identifiers include Global Trade Item Number (GTIN) and Manufacturer Part Numbers (MPNs). In addition, when using identification codes, it is best to meet three characteristics:</p>
<ul><li><strong>Uniqueness:</strong>Products must have a unique identification code. Regardless of physical or e-commerce, an identification code must correspond to a product and vice versa.</li><li><strong>Verifiability:</strong>The identification code must be able to verify the manufacturer and other product information.</li><li><strong>Global Reach:</strong>The product identification system is global and can maintain seamless integration when products circulate in different regions.</li></ul>
<p>In addition, this announcement also provides some suggestions for the use of identification codes for (1.) brands and manufacturers, (2.) retailers and third-party sellers, (3.) publishers (ex: when reviewing products), basically using GTIN and structured data correctly to let Google know that "the product you are referring to is the product that Google knows."</p>
<p>link:<a class="rank-math-link" href="https://developers.google.com/search/blog/2021/02/product-information">Official announcement</a></p>

<h2 id="toc-8">Google Search Podcast EP. 14 Summary</h2>
<p>The episode is titled "<em>Site Kit, Web Components, shards and more!</em>", discussed several things, which are very technical and have little to do with SEO, but I personally find them quite interesting, so I will translate them a little bit.</p>
<figure class="embed embed--spotify"><iframe allow="autoplay; clipboard-write; encrypted-media; fullscreen; picture-in-picture" loading="lazy" src="https://open.spotify.com/embed/episode/1Z3G2lILU9sVKX0H4ur8uM" title="Spotify episode"></iframe><figcaption><a href="https://open.spotify.com/episode/1Z3G2lILU9sVKX0H4ur8uM" rel="noopener noreferrer">View original content on Spotify</a></figcaption></figure>
<p><strong>Site Kit<br/></strong>An open source tool that facilitates webmasters to integrate their websites with other Google platforms (GA, AdSense, GSC...). It is developed and maintained by Google. Currently, there are<a class="rank-math-link" href="https://wordpress.org/plugins/google-site-kit/">WordPress plug-in</a>, and other platforms are under development.</p>
<p><strong>Web Components</strong><br/>Web Components allow developers to customize new HTML Tags (for example, when inserting YouTube videos, you can use<a class="rank-math-link" href="https://github.com/paulirish/lite-youtube-embed">&lt;lite-youtube&gt;</a>This is a more performance optimized plugin), but most importantly<strong>Googlebot can crawl the content in the customized web component</strong>, if you have heard of shadow DOM, this refers to the same thing. (<a href="https://developers.google.com/search/docs/guides/javascript-seo-basics#web-components">Further reading</a>)</p>
<p><strong>Shards</strong><br/>Gary continues what was discussed previously<a class="rank-math-link" href="./seo-newsletter-issue-25.html#toc-8:~:text=Gary%E6%8F%90%E5%88%B0Google%E7%9A%84%E7%B4%A2%E5%BC%95%E5%85%B6%E5%AF%A6%E6%98%AF%E6%9C%89%E7%AD%89%E7%B4%9A%E4%B9%8B%E5%88%86%E7%9A%84">Indexing Tiers</a>talks about "serving index", which is the index database that is actually used to run after the user enters a search word. There are several such data centers around the world, and each data center has the same index database (if synchronization is completed), so if all conditions are the same, the search results will theoretically be the same.
The</p>
<p>database is composed of<a class="rank-math-link" href="https://www.mdeditor.tw/pl/2A5M/zh-tw">shards (shards)</a>, but even the smallest shard is very large. To find the most matching file from all shards in a few seconds, and then return the result to the user, Google also uses "shard indexes", "the posting list" and other methods, but the purpose is nothing more than to query the database more efficiently.</p>
<figure class="wp-block-image size-large"><img alt="Illustration for SEO e-Newsletter Issue 27 – 2021.02.16~2021.02.28" class="wp-image-2599" decoding="async" height="391" loading="lazy" src="./wp-content/uploads/2021/02/gary-%E8%A7%A3%E9%87%8BGoogle%E7%B4%A2%E5%BC%95%E8%B3%87%E6%96%99%E5%BA%AB%E7%9A%84query%E6%96%B9%E6%B3%95.png" width="679"/><figcaption>Gary explains the mechanics behind search results</figcaption></figure>
