<h2 id="toc-1">Bing Webmaster Tools overhaul</h2>
<p>Bing announced at SMX West that it will make a major update to its webmaster tools. Now you can see a new interface in the three reports of "Website Performance", "Site Map" and "Backlinks". This interface will be officially launched in the first week of March.</p>
<p>As long as the website has Google's webmaster tools certified, it can indirectly certify Bing's webmaster tools. It is recommended that those who have not used Bing take some time to set it up. It can be completed in 3 to 5 minutes.</p>

<h2 id="toc-2">Reminder: Google will start crawling nofollow links after 3/1</h2>
<p>This is last year's announcement - starting from March 1, 2020, Google will use the rel="nofollow" attribute in the link as a reference, and will still crawl the URL in nofollow. In addition, two new link attributes - "ugc" and "sponsored" are added to mark different links.</p>

<p>To put it simply, after Chrome version 80, if third-party cookies are not added with the SameSite attribute, they may be blocked by Chrome during transmission. To debug, go to your website and open Developer tools &gt; Console and see if there is a message similar to the one below, which will detail the cookies from which sources will expire after the update. If there are cookies that will affect the operation of the website, please ask the other party to add the appropriate SameSite attribute.</p>

<h2 id="toc-10">Hitwise will follow Jumpshot into history</h2>
<p>Jumpshot is a subsidiary of the anti-virus software Avast. It was recently revealed that it was collecting user information and decided to cease operations. Hitwise, another online user data provider similar to Jumpshot, also announced on its website in mid-February that it would cease operations. The data provided by these two manufacturers is the source of information for many third-party SEO tools. In an era of rising user privacy, this information will only become more and more rare in the future.</p>
