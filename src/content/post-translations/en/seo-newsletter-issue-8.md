<h2>Three pillars of web UX indicators - LCP / FID / CLS</h2>
<p>The user experience of web pages has always been difficult to quantify. The Chrome department hopes to solve this pain point, selects three core indicators, and sets standards for each indicator, hoping to systematize UX measurement indicators. These three indicators are:</p>
<ul><li>Largest Contentful Paint (LCP): Measures website speed</li><li>First Input Delay (FID): Measures website interactivity</li><li>Cumulative Layout Shift (CLS): Measures the visual stability of web page components</li></ul>
<figure class="wp-block-image size-large"><img alt="Three major indicators of website UX" class="wp-image-1165" decoding="async" height="517" loading="lazy" src="./wp-content/uploads/2020/05/UX%E4%B8%89%E5%A4%A7%E6%8C%87%E6%A8%99.jpg" width="900"/></figure>
<p>The standard proposed by Chrome cannot be underestimated. Many tools have responded and will start to use these three indicators as the axis, including PageSpeed Insights, WebPageTest, CrUX, Lighthouse... etc., etc. have announced that they will start to support it in the near future, which will be introduced below.</p>
<p>link:<a href="https://blog.chromium.org/2020/05/introducing-web-vitals-essential-metrics.html">Chromium Article</a> / <a href="https://web.dev/vitals/">web.dev article</a> / <a href="https://blog.amp.dev/2020/05/06/amp-web-vitals-a-better-web-together/">amp.dev article</a> / <a href="https://www.ithome.com.tw/news/137434">(Chinese) iThome report</a></p>

<h2>WebPageTest supports Web Vitals</h2>
<p>WebPageTest is a very useful tool when testing web page speed. This tool now uses Web Vitals as an important indicator in the report. It will also show the LCP determined by Chrome in the frame-by-frame video of the page loading, and frame it with a red line.</p>
<blockquote class="embed embed--twitter"><p>Twitter／X Post</p><a href="https://twitter.com/patmeenan/status/1260294231589113859" rel="noopener noreferrer">View original post on Twitter／X</a></blockquote>
<p>Note: FID cannot be calculated through test tools because the tools do not "interact" with the web page, so when using Lab Data, Total Blocking Time (TBT) is usually used instead. TBT is another metric (web vital), but it is not the core metric (web core vital) defined by the Chrome Team.</p>
<p>link:<a href="https://webpagetest.org/">WebPageTest tool</a></p>

<h2>CrUX Report LogWeb Vitals</h2>
<p>Chrome User Experience (CrUX) is a public database that records the web performance of Chrome users when browsing the web. Compared with Lab Data of general measurement tools, CrUX data is Field Data and is quite precious. This public information has also begun to record three web core vitals, which can be run using Google BigQuery. The following are the results of the 104 Labor Bank website.</p>
<figure class="wp-block-image size-large"><img alt="Illustration for SEO e-Newsletter Issue 8 – 2020.05.01~2020.05.15" class="wp-image-1172" decoding="async" height="665" loading="lazy" src="./wp-content/uploads/2020/05/104%E4%BA%BA%E5%8A%9B%E9%8A%80%E8%A1%8C%E7%B6%B2%E7%AB%99%E7%94%A8%E6%88%B6%E9%AB%94%E9%A9%97-1024x665.png" width="1024"/></figure>
<p>The above data can be interpreted as: 92.08% of users have good LCP loading time (&lt;2500ms) when browsing the 104 Human Bank website (www.104.com.tw), 4.97% have normal (&gt;=2500ms, &lt;4000ms), 2.91% is bad (&gt;=4000ms), where the 75th percentile LCP is 1400ms.</p>

<h2>Google’s Question Hub project</h2>
<p>Google has a Question Hub project that collects questions that users have not found satisfactory answers to on Google and organizes them in one place so that online media can see them and create appropriate content. This is a very useful tool that allows content producers to see unanswered questions on the Internet, and from real people!</p>
<p>This project was launched in India last year and is still in Beta testing. Recently, there are signs of preparation for launch in the United States. The author is in the United States and when searching on Google, I am often asked under the SERP whether my question has been answered, and if not, what is my question.</p>
