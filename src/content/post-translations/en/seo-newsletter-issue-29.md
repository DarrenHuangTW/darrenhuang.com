<h2>What should I do if the website server is temporarily broken?</h2>
<p>If the website server hangs up for some reason (traffic overload, server failure, attack...), apart from the engineers jumping around, how should SEOs deal with such a situation? John Muller gave quite complete advice on such a situation on Twitter.</p>
<blockquote class="embed embed--twitter"><p>Twitter／X Post</p><a href="https://twitter.com/johnmu/status/1369939925064355841" rel="noopener noreferrer">View original post on Twitter／X</a></blockquote>
<p>The original thread has more suggestions, but the more important ones include:</p>
<ol><li>Ask the server to return a 503 code (Service Unavailable). Do not use 200 or 404. If the entire host hangs up and there is no response at all, you can point the DNS to other hosts and return 503.</li><li>Select a few of the most important pages and make static HTML versions, upload and use the same URL, so that users can still see important information. (Bonus: You can find the page at https://archive.org/ and save it.)</li><li>can design a beautiful-looking 503 page and put appropriate messages. Usually the default error screen of the server is very positive.</li></ol>

<h2 id="toc-6">Google Discovery and News systems are not exactly the same</h2>
<p>In an Office Hour, John said: A web page can appear on Google News but not on Google Explore, and vice versa.</p>
<p>If some pages of the same website comply with the specifications, but some pages do not, Google Discover may choose not to publish the content of the website. Generally speaking, Google's standards for exploration are higher than other places because this placement is actively pushed to users; in contrast, search or news are actively searched by users.</p>

<h2 id="toc-9">Google Core Web Vitals Official Questions and Answers</h2>
<p>Regarding the core algorithm changes that will be launched in May, Google has collected many common questions and compiled them into a Q&amp;A collection. I have translated some concepts that I think are very important and put them below. However, I still recommend that everyone read the original post. If you have different interpretations, please leave a message for discussion!</p>
<p><strong>Q: <a class="rank-math-link" href="https://support.google.com/webmasters/thread/104436075?hl=en#gbwa:~:text=Where%20does%20the%20Core%20Web%20Vitals%20data%20that%20Search%20considers%20come%20from%3F">What is the score of each web page based on?</a></strong><br/>A: The 75th percentile score of all visitors to this page based on the past 28 days. In other words, if 75% of visitors have a "good" experience, the page will be classified as having a "good" performance.</p>
<p><strong>Q: <a class="rank-math-link" href="https://support.google.com/webmasters/thread/104436075?hl=en#gbwa:~:text=How%20are%20scores%20for%20individual%20URLs,or%20fails%20the%20web%20vitals%20assessment%3F">What if the web page is newly published?</a></strong><br/>A: We will use some mechanisms to tie similar pages together and calculate their scores. This also applies to web pages/websites with low traffic.</p>
<p><strong>Q: <a class="rank-math-link" href="https://support.google.com/webmasters/thread/104436075?hl=en#gbwa:~:text=Q%3A%20How%20does%20page%20experience%20ranking,are%20considered%20in%20the%20%E2%80%9Cgood%E2%80%9D%20threshold%3F">How does CWV score affect page ranking?</a></strong><br/>A: The three scores of LCP, FID and CLS affect the ranking separately. As long as they are in the same range, the ranking impact will be the same. For example, a web page with an LCP 200ms and a web page with an LCP 1500ms both fall within the "good" range defined by LCP (&lt;2500 ms). Therefore, the ranking impact at this point in the LCP is the same.</p>
<p><strong>Q: <a class="rank-math-link" href="https://support.google.com/webmasters/thread/104436075?hl=en#gbwa:~:text=Q%3A%20Am%20I%20eligible%20for%20Top%20Stories%20carousel%20if%20my%20webpage%20is%20not%20clearing%20Core%20Web%20Vitals%3F">Will CWV affect a website’s eligibility to appear on Top Stories?</a></strong><br/>A: No, the page experience will affect the ranking, but it will not affect the eligibility to appear in Top Stories. In the future, compliance with Google News content policies will be the only condition for appearing in Top Stories (not AMP; not the web experience).</p>
