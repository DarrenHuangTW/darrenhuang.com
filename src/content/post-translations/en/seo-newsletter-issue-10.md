<h2>Chrome 84 will block HTTP loading image resources</h2>
<p>is in<a aria-label=" (在新分頁中開啟)" href="./seo-newsletter-issue-5.html#toc-11" rel="noreferrer noopener" target="_blank">The fifth issue of e-newsletter</a>This update was introduced, but it was later delayed for some reason, but this feature will finally be released in Chrome version 84 (expected to be launched on July 14). If the images on the website are HTTP, Chrome will automatically upgrade them to HTTPS. But if HTTPS fails to load, the image will not be loaded.</p>
<p>Mixed Content is a very common problem in SEO, especially when images are provided through CDN instead of being placed in the same domain. The webmaster only remembers to install HTTPS for his own domain and forgets about the CDN server. It is recommended that you take some time to check the website for such problems.</p>
