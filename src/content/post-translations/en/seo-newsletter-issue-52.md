<h2 id="toc-2">[Trivia] Sitemap can contain the URLs of other subfolders</h2>
<p>Robots.txt can only be placed in the root directory of the website, while Sitemap can be placed in any subfolder. The general understanding is that in which subdirectory the sitemap is placed, the file can only contain URLs in that subdirectory. For example, if the sitemap is located at<code>https://www.example.com/folder-1/sitemap.xml</code>, only items containing
The URL of<code>/folder-1/</code>.</p>
<p>But in fact, there is an exception to the above narrative. John recently answered this question on Twitter, that is, when<code>/folder-1/</code>and<code>/folder-2/</code>When both subdirectories have been certified by the GSC of the same account, then<code>/folder-1/</code>can contain non-
The URL of<code>/folder-1/</code>.</p>

<h2 id="toc-3">[News] CrUX starts recording new "interactive" metric (experimental)</h2>
<p>web experience<a href="./core-web-vitals-lcp-fid-cls.html#:~:text=%E9%80%99%E4%B8%89%E5%80%8B%E6%8C%87%E6%A8%99%E5%88%86%E5%88%A5%E4%BB%A3%E8%A1%A8%E4%BA%86%E4%B8%80%E5%80%8B%E7%B6%B2%E9%A0%81%E7%9A%84%E3%80%8C%E8%BC%89%E5%85%A5%E9%80%9F%E5%BA%A6%E3%80%8D%E3%80%81%E3%80%8C%E4%BA%92%E5%8B%95%E6%80%A7%E3%80%8D%E3%80%81%E3%80%8C%E7%A9%A9%E5%AE%9A%E6%80%A7%E3%80%8D%E3%80%82">three major indicators</a>, respectively quantify the "<em>loading speed</em>」、「<em>Interactivity</em>」、「<em>stability</em>". Interactivity is currently measured by First Input Delay, but this indicator has two fatal flaws - (1.) It only calculates the delay of the user's first interaction with the web page, and does not record subsequent interactive experiences. For example, the first interaction on many websites is to turn off cookie notifications, and the real meaningful interactions are the subsequent actions; (2.) In addition, it only records the time difference between the user's interaction and the "start of response" of the web page, and does not take the "response time" into consideration. Therefore, the web page starts running immediately after pressing the first button, but it takes 10 seconds to complete. There will still be a high FID score.</p>
<p>In this regard, Chrome is going to launch a new responsiveness indicator, which can already be seen in the Chrome UX Report, called<code>experimental.responsiveness</code>is still a test, so I won’t introduce it much. If you are interested in knowing the technical details, you can refer to this article.
Articles on<a href="https://web.dev/responsiveness/">web.dev</a>。</p>

<p>This episode features Danielle Marshak, one of the product managers on the Google search team, mainly responsible for videos.</p>
<p>The core purpose of Google search is to organize information on the Internet, and video is undoubtedly an important information source medium. In the past few years, Google searches have<a href="./seo-newsletter-issue-50.html#toc-9">text understanding</a>'s technology is growing rapidly. Similarly, when Google makes more breakthroughs in non-text carrier information processing technology, it should not be too surprising that more images and videos will be seen in search results.</p>
<p>Danielle talked about several ways Google understands video content (in<a href="./seo-newsletter-issue-44.html#toc-9">Issue 44</a>has been covered), and also emphasized
Structured data for<a href="https://developers.google.com/search/docs/advanced/structured-data/video">video</a>, as well as the text content on the web page where the video is located, are of great help to Google in understanding the video information, because the visual recognition technology of computers is still a long way from being mature. An example is judgment<a href="https://www.google.com/search?q=Chihuahua+or+muffin">Chihuahua and Muffin</a>(or<a href="https://tw.news.yahoo.com/%E5%A4%8F%E4%BA%8E%E5%96%AC%E5%AE%8B%E8%8A%B8%E6%A8%BA%E5%90%8C%E6%A1%86%E9%A3%86%E6%88%B2-%E8%87%89%E7%9B%B2%E7%B6%B2%E5%8F%8B%E5%B4%A9%E6%BD%B0-073006552.html">Xia Yuqiao and Song Yunhua</a>)。</p>
<p>Finally, Danielle mentioned that her team now has two focuses. One is how to use "video understanding" to help users find the information they want faster, such as<a href="./seo-newsletter-issue-37.html#toc-5">key moment</a>; the other is how to better integrate videos into the search experience and determine whether the user's search terms are more suitable (or less suitable) to use videos to find answers.</p>
