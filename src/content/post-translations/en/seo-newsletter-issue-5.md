<h2 id="toc-3">Bing launches URL/content submission API</h2>
<p>Bing has launched these two APIs, allowing webmasters to immediately submit these changes to Bing when a new webpage is launched or the webpage content is changed, without having to wait for Bingbot to crawl and index it. Both APIs were in closed beta before, but now the URL Submission API is open to everyone.</p>
<p>The upper limit of the URL submission API is 10,000 URLs per day, and 3XX or 4XX URLs can be submitted to let Bing know about changes on the website.</p>
<pre class="wp-block-preformatted">JSON request sample:

POST /webmaster/api.svc/json/SubmitUrlbatch?​apikey=REDACTED HTTP/1.1​
Content-Type: application/json; charset=utf-8​
Host: ssl.bing.com​

{
"siteUrl":"http://yoursite.com",​
"urlList":[
"http://yoursite.com/url1",
"http://yoursite.com/url2",
"http://yoursite.com/url3"
]
}</pre>

<h2 id="toc-11">Chrome 81 will start blocking image resources loaded by HTTP</h2>
<p>Starting from Chrome 81 (expected to be released on 2020.04.07), Chrome will automatically upgrade to HTTPS for images loaded using HTTP. If HTTPS fails to capture resources, the image will<strong>No</strong>is loaded.</p>
<p>Mixed Content is a very common problem in SEO, especially when images are provided through CDN instead of being placed in the same domain. The webmaster only remembers to install HTTPS for his own domain and forgets about the CDN server. It is recommended that you take some time to check the website for such problems.</p>
