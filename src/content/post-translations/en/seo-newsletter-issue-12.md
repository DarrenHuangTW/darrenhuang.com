<h2 id="toc-2">Structured data testing tool will be replaced</h2>
<p>Structured Data Testing Tool (SDTT, Structured Data Testing Tool) will be discontinued and replaced by Rich Results Test (RRT, Complex Search Results Testing Tool).</p>
<p>The biggest difference between the two is that SDTT can test any schema markup, regardless of whether there are any appearance changes in the search results. For example, if there is a "<a aria-label="undefined (opens in a new tab)" href="https://schema.org/VideoGame" rel="noreferrer noopener" target="_blank">VideoGame</a>" tag. Adding this tag to the web page will not cause any difference in search appearance. You can use SDTT on this page to see if the code is installed correctly, but on RRT it will only show that it does not meet the conditions.</p>

<p>Martin Splitt held an AMA (Ask Me Anything) on Reddit, which answered many questions about Javascript and SEO.</p>
<figure class="wp-block-image size-large"><img alt="Martin explains that 2 wave indexing is no longer used" class="wp-image-1556" decoding="async" height="301" loading="lazy" src="./wp-content/uploads/2020/07/%E5%85%A9%E9%9A%8E%E6%AE%B5indexing-1024x301.png" width="1024"/></figure>

Basically every web page now has a rendering process, and the median time a web page waits for rendering is only about five seconds.</p>
