These steps may not be particularly time-consuming, but if there is a tool that allows you to check the Alt Tag of each image on a webpage with just one click, see the cache of the webpage with just one click, and even see the Title, Description, and other Meta Tags of the page with just one click, it will definitely save a lot of time! This article is going to share a few Bookmarklets that I commonly use and like very much. I hope it can be helpful to SEOs!<div></div>
<h2>What is Bookmarklet?</h2>Bookmarklet is called a small bookmark in Chinese. The difference from ordinary bookmarks is that<b>It is a string of JavaScript instead of a URL</b>. For example, engineers can write a command: tell me what the rel canonical tag of the current webpage is. After putting this command into the browser's bookmark bar, when you want to check the website in the future, you only need to click on the small bookmark, and the answer will be directly told to you!<h2>How to use</h2>The advantage of bookmarklets is that they are super easy to use. Even if you don’t know how to code, as long as you find someone to share it (like this article), drag the link to the bookmark bar for easy use in the future.<img alt="SEO bookmarklet" class="wp-image-135 size-full aligncenter" decoding="async" height="286" loading="lazy" src="./wp-content/uploads/2016/06/SEO%E5%B0%8F%E6%9B%B8%E7%B1%A4.gif" width="600"/>

<h2>10 commonly used bookmarks for SEOs</h2>Listed below are some of my most commonly used functions, including checking meta robots tag, canonical tag, Wayback Machine, Google Page Speed Insights, opening Open Site Explorer...etc., without further ado, let’s try it out together!<h3>1. Check how many pages of the current website are indexed</h3>
<blockquote>Bookmarklet: <a>Site Search(site:+domain)</a></blockquote>Enter site:www.example.com into Google to find out how many pages of a website are indexed by Google. This command is definitely very familiar to most SEOs, and this small bookmark allows you to search for Site+domain no matter which page on the website you are on without having to copy and paste it back and forth.<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-136 size-full" decoding="async" height="249" loading="lazy" src="./wp-content/uploads/2016/06/site-operator.jpg" width="798"/>
<h3>2. Check whether the current web page is indexed</h3>
<blockquote>Bookmarklet: <a>Info Search(site:+current page)</a></blockquote>This is the only bookmarklet I will introduce in this article that I wrote myself XD. It is mainly used to check whether the current page has been indexed by Google. Suppose you are now<a href="https://moz.com/blog">https://moz.com/blog</a>, using this bookmark allows you to see whether the page has been indexed, without other pages under /blog appearing.<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-137 size-full" decoding="async" height="268" loading="lazy" src="./wp-content/uploads/2016/06/info-operator.jpg" width="804"/>

 
<h3>3. Check the Cache version of the current web page</h3>
<blockquote>Bookmarklet: <a>Google Cache</a></blockquote>The concepts between Crawl / Index / Cache will not be described in detail. Simply put, this small bookmark allows you to see what the current web page looks like in the eyes of Google. After the web page content is changed, you may often use it to see if Google has noticed the change.<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-138 size-full" decoding="async" height="114" loading="lazy" src="./wp-content/uploads/2016/06/google-cache-version.jpg" width="1267"/>

 
<h3>4. Open Open Site Explorer to check the current web page</h3>
<blockquote>Bookmarklet: <a>Use OSE to view current web page information</a></blockquote>I wrote an article before about<a href="./seo-backlinks-tool-open-site-explorer-ose.html" rel="noopener noreferrer" target="_blank">This tool from Moz Open Site Explorer</a>, you can use this bookmark to open OSE directly and see some basic information about the page you are on (DA/PA, inbound links...etc.), it is very useful for people with Moz Pro!<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-139 size-large" decoding="async" height="507" loading="lazy" src="./wp-content/uploads/2016/06/open-site-explorer-1024x507.jpg" width="1024"/>

 
<h3>5. Check the Canonical Tag of the current page</h3>
<blockquote>Bookmarklet: <a>Check the canonical tag</a></blockquote>When you click on it, a small box will pop up to tell you whether the current page has a rel canonical tag, and if so, where to canonicalize it, &lt; link href="https://darrenhuang.com/" rel="canonical" /&gt;.<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-140 size-full" decoding="async" height="195" loading="lazy" src="./wp-content/uploads/2016/06/check-canonical-tag.jpg" width="503"/>

 
<h3>6. Check the meta robots tag of the current web page</h3>
<blockquote>Bookmarklet: <a>Check meta robots tag</a></blockquote>This small bookmark will check the meta robots tag of the current website, and will pop up a box to tell you whether there are index/noindex, follow/nofollow, noodp, noydir, nocache, noarchive....etc. instructions in the robots meta tag.<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-142 size-full" decoding="async" height="188" loading="lazy" src="./wp-content/uploads/2016/06/check-meta-robots-tag.jpg" width="484"/>

 
<h3>7. Use Wayback Machine to see how the current web page looked before</h3>
<blockquote>Bookmarklet: <a>Wayback Machine</a></blockquote>Wayback Machine allows you to see what a web page looked like before*. This small bookmark allows you to enter Wayback Machine with one click to analyze the results of the current web page, and then select a date to see what the web page looked like in different periods.
(*Note: Not every web page will be accessed!)<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-143 size-large" decoding="async" height="502" loading="lazy" src="./wp-content/uploads/2016/06/wayback-machine-1024x502.jpg" width="1024"/>

 
<h3>8. Check the Page Speed Insights of the current web page</h3>
<blockquote>Bookmarklet: <a>Google Page Speed Insights</a></blockquote>People with some experience should be familiar with this tool. It can analyze the reading speed of web pages. This small bookmark saves you from opening new tabs, searching, copying and pasting. It can be done with one click!<img alt="Illustration for SEO| Bookmarklets - A practical tool for SEO" class="aligncenter wp-image-144 size-large" decoding="async" height="503" loading="lazy" src="./wp-content/uploads/2016/06/google-page-speed-insights-1024x503.jpg" width="1024"/>

 
<h3>9. Alt Tag that shows all images on this web page</h3>
