<h2 id="toc-2">Chrome80 will be preset to not allow push notifications</h2>

<h2 id="toc-5">Google will no longer support Data-vocabulary.org's structured markup</h2>
<p>Data-vocabulary is an early "vocabulary" standard of Structured Data, and is now replaced by Schema Markup. After April 2020, data-vocabulary tags will not generate any possible compound search results.</p>

<h2 id="toc-9">GSC newly added URL removal tool</h2>
<p>This URL removal tool was finally moved after the GSC revision. This block is divided into three items:</p>
<ul><li><strong>temporarily removed</strong>: Allows webmasters to "quickly" remove URLs from search results "temporarily". (Note: Validity period is only six months).</li><li><strong>Outdated content</strong>: This can be used to submit outdated web pages. It is used when the content on the web page no longer exists but still appears in the search results. Anyone can report here.</li><li><strong>Safe Search:</strong>When there is content on the website that is reported as adult content by users, it will appear here.</li></ul>
