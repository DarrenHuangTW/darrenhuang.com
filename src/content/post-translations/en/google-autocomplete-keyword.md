<h2>Introduction to Autocomplete API</h2>
<p>The structure of Google's auto-complete API is very simple. Send a GET request to the target location and you can get back a JSON file, which contains the auto-complete predicted words during search.</p>
<ul><li>API location:<code>http://suggestqueries.google.com/complete/search</code></li><li>parameters:<ul><li><code>output</code>= required, firefox or chrome</li><li><code>q</code>= Required, search word, spaces separated by plus sign (+)</li><li><code>hl</code>= optional, language setting (e.g. en, zh-TW, jp)</li><li><code>gl</code>= optional, region setting (e.g. us, tw, sg)</li></ul></li></ul>
<p>Example: Enter in the address bar<code>http://suggestqueries.google.com/complete/search?output=firefox&amp;q=台積電&amp;hl=zh-tw&amp;gl=tw</code>can see the returned file.</p>
