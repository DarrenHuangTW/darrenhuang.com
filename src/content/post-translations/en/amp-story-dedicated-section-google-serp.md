<p>At the AMP conference in April 2019, Google announced that in the general Google search page,<strong>AMP Story will have its own exclusive section</strong>. <h2>What is AMP?</h2>
<p>AMP, whose full name is Accelerated Mobile Page, is a network architecture developed by Google to significantly improve website speed and user experience. When an AMP web page loads, there is often almost no noticeable delay.</p>
<p>This site is completely AMP-based. If readers search and enter this site on their mobile phones, they can clearly feel the speed advantage of AMP web pages.</p>

<h2>What are Web Stories (AMP Stories)?</h2>
<p>AMP Stories was renamed Web Stories in May 2020. Since the technical architecture behind it is AMP, and the early name was AMP Stories, you can still see some people calling it AMP Stories, but the correct official name is Web Stories.</p>
<p>Similar to the limited-time updates of Instagram and Facebook, web stories use a more visual way to deliver content while maintaining the advantage of speed. Many American publishing media have adopted similar technology.</p>
<p>Different from the actual dynamics of social media, Web Story (AMP Story) is a web page with its own URL, so search engines can crawl and index the content on it, and anyone can find Web Story through search or directly entering the URL in the browser.</p>

<h2>Web Story</h2>
<p>Just like AMP, Web Story is essentially HTML, but has a specific format and syntax. A Web Story is composed of several "Pages"; a Page is composed of several "Layers" superimposed, and a Layer contains various "Elements" required by the Layer.</p>
