<h2 id="toc-6">[Good article] How to quantify marketing channels that are difficult to quantify</h2>
<p>This article was written by the long-lost Rand Fishkin. The opening paragraph of the article attracted my attention. He said that too many company executives now only focus on measurable marketing proposals. If it is growth channels that are difficult to measure accurately, such as PR, community management, and activities, they are often not taken seriously. Marketing Before the rise of online privacy, marketers had a lot of data, which fostered everyone's reliance on "traceability." As the Internet ecosystem becomes more complex, there is now less and less data to rely on.</p>
<p>It is true that some very cool analysis models have appeared on the market to try to reconstruct the lost data, but maybe what everyone should think about is to think from a different angle and use more indirect methods that require some intuition and creativity to measure what we are doing, rather than blindly trusting the data spit out by the tools. This is back to the way marketers measured TV advertising, in-store promotions, radio, etc. before the advent of the Internet.</p>

<p>I believe everyone knows that multi-national/multi-language websites can use hreflang to declare, but what if the content has a more detailed regional nature, such as a state in the United States or a province in Canada? John did not have a very positive answer in this video, but he said that Googlebot usually only comes from one place (<a href="https://www.searchenginejournal.com/googles-advice-for-targeting-multiple-locations-with-one-website/433846/#close:~:text=that%20would%20map-,back%20to%20California,-.">California, United States</a>), so IP-redirect or limiting web pages to only people in specific areas are very bad.</p>

<p>Some people think that every web page must put
The webpage will be included only if you have the tag<code>&lt;meta name="robots" content="index, follow"&gt;</code>, but this is actually completely unnecessary. <h2 id="toc-10">[Abstract] Let’s talk about image SEO</h2>
<figure class="embed embed--youtube"><div class="embed__frame"><iframe allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen="" loading="lazy" referrerpolicy="strict-origin-when-cross-origin" src="https://www.youtube-nocookie.com/embed/TaPhj4-bxkQ" title="YouTube video player"></iframe></div><figcaption><a href="https://www.youtube.com/watch?v=TaPhj4-bxkQ" rel="noopener noreferrer">View original video on YouTube</a></figcaption></figure>
<p>This podcast episode features John and Lizzi discussing image SEO. John said something that I deeply agree with. He said that many SEO personnel directly want to jump into the N methods of optimizing image SEO, but they should go to a higher level and first think about whether the images on the website have any "search value". If so, then think about how to optimize them, because not every image should have keywords, such as decorative images or functional patterns.</p>
<p>In addition, if the file name of the image contains descriptive text, it can help search engines understand its content, but John does not think this is a big factor. If the image already has alt text or there is related content nearby the image, then Google can usually already understand what the image is related to. This is very similar to the discussion of whether a website should have keywords. If it does, it’s good, but if it doesn’t, there’s no need to change it just for the sake of changing it.</p>
<p>The last point is an important point that I haven't thought about before, but it is also quite reasonable. The same image often has different sizes, crops, or file formats. It is completely OK to have them all included by Google. Google's system will determine by itself which images are actually the same file. This is different from using canonical to declare different web addresses.</p>
