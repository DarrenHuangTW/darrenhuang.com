<h2 id="toc-3">Lighthouse 8.0 Update</h2>
<p>Lighthouse, a suite for measuring web user experience, has launched version 8.0, with some noteworthy updates.</p>
<p>First of all, the weight of each score has been adjusted. All three indicators of CWV have been improved. Among them, the proportion of CLS has increased the most, mainly because of its<a href="https://web.dev/cls-web-tooling/">calculation method
Changes to</a>(more reasonable for CLS of SPA type web pages). In addition, the announcement also stated that they expect to reduce their reliance on TTI in the future because TBT is more stable and both are indicators of interactivity.</p>

<h2 id="toc-7">[Black hat SEO case] Building backlinks vs ranking</h2>
<p>in<a href="https://www.reddit.com/r/webdev/comments/nure5l/the_topranking_html_editor_on_google_is_an_seo/">Foreign Forum
I read this interesting case on</a>. One day, an engineer found that his website ranking was surpassed by an unknown website. After a series of detective work, he found that the first-ranked web page had received a large number of external links in a short period of time.</p>
<figure class="wp-block-image size-large is-resized"><img alt="Illustration for SEO e-Newsletter Issue 34 – 2021.06.01~2021.06.15" class="wp-image-2785" decoding="async" height="298" loading="lazy" src="./wp-content/uploads/2021/06/seo-google-serp.png" width="768"/><figcaption>The author's website was pushed to the second place</figcaption></figure>
<div class="wp-block-image"><figure class="aligncenter size-large is-resized"><img alt="Illustration for SEO e-Newsletter Issue 34 – 2021.06.01~2021.06.15" class="wp-image-2786" decoding="async" height="228" loading="lazy" src="./wp-content/uploads/2021/06/seo-backlinks.png" width="542"/><figcaption>The first web page has a large number of external links</figcaption></figure></div>
<p>After contacting several websites, he found one thing in common. These web pages that provide external links all use the same HTML cleaner (a tool that organizes and cleans HTML to make it readable), and this tool secretly inserts links into the "cleaned" HTML. After that, the author continued to dig and found other websites that relied on the same method to obtain rankings, as well as similar tools.</p>
<p>This article is quite popular abroad, because the author is not a professional SEO, and many people only realized that they had used such tools after reading the article, and inadvertently provided links. From an SEO perspective, although Google always says that they can now effectively prevent and control such black hat methods, according to the picture above, the influence of external links is still quite large!</p>

<h2 id="toc-8">[Video] Top Stories carousel placement changes</h2>
<p>This video summarizes the upcoming changes to Top Stories. First of all, AMP is no longer a necessary condition, and any webpage with a good webpage experience will have the opportunity. In addition, the AMP icon (⚡) will be removed, and there will no longer be any difference in the appearance of regular web pages and AMP web pages in search results.</p>
<p>AMP Cache is one of the reasons why AMP web pages can be loaded with almost zero delay, and now ordinary web pages can also use<a href="https://developers.google.com/search/docs/advanced/experience/signed-exchange">Signed Exchange</a>This technology allows Google to pre-crawl non-AMP web content to achieve this zero-delay loading effect.</p>
<p>Finally, since Top Stories is open to non-AMP web pages, this placement will become more competitive. To appear here, web pages must (1.) comply with<a href="https://support.google.com/news/publisher-center/answer/6204050">Google News Policy</a>, (2.) Have good web page experience scores (CWVs), (3.) Use structured markup of Article</p>

<h2 id="toc-10">[Video] Are there any indexing restrictions on Google?</h2>
<p>The question John answers in this video is "<em>Is there a limit to the number of .html static pages that Google can index?</em>", the answer is "no", but John added two points: (1.) Google will not know or care whether the web page is a static page or a dynamic page (the server returns different files according to different conditions), even a dynamic page can have a .html ending. (2.) Although there is no limit on the number, Google's resources are not unlimited. In theory, they will only index the pages that need to be indexed.</p>
