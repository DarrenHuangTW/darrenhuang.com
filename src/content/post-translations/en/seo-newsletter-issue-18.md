<h3>1. <strong>BERT</strong> [07:36]</h3>
<p><a href="https://www.facebook.com/searchenginecommunity/posts/5704429170">BERT applied to search from 2019</a>, which affected 1/10 of the English search results in the United States, is now applied to almost every search term, and has also expanded to other languages.</p>
<h3>2. <strong>Continuous testing and optimization</strong> [08:57]</h3>
<p>To optimize search results, Google conducts thousands of tests every year, and there were more than 3,600 updates in 2019.</p>
<h3><strong>3. Spelling errors</strong></h3>
<p>One in every 10 search terms has a spelling error, and Google is launching a new algorithm that uses machine learning to improve its judgment. This update is more advanced than any other spelling error change in the past five years.</p>
<h3><strong>4. Specific information search/fragment information index</strong> [17:16]</h3>
<p>Sometimes the answer that the user is looking for is hidden in a small paragraph in the web page. In this case, although the passage information meets the search intent, the search term has low relevance to the main theme of the entire web page, so the relevance of the key fragment information is diluted and the ranking suffers (because there is too much content on the page that is not related to the search term).</p>
<p><strong>With this update, Google will base its rankings on the relevance of fragment information and search terms, rather than on the relevance of the entire web page and search terms.</strong>(Note: The content of the entire webpage will still be indexed, but the ranking will be based on fragment relevance rather than overall webpage relevance)</p>
<p class="has-bright-red-color has-text-color"><strong>This update will be rolled out before the end of the year, starting with English searches in the United States, but will gradually expand to every language in the world. When fully rolled out, it will affect about 7% of search terms.</strong>。</p>
<p>The example given in the video is "<em>How do I know if my glass is UV resistant?
The word "</em>" originally ranked first (Figure A) was an article about anti-UV glass. It talked about different ultraviolet wavelengths, which type of glass is most effective... and so on. It was quite professional but did not answer the searcher's question. The first place after this change (Figure B) is a forum article. You can see that the entire webpage is very long and contains a lot of irrelevant noise (the following is a bit like a villager's pen battle...), but there is a short paragraph in the middle (yellow block) that accurately answers the search question.</p>

<h3>5. Provide subtopics and diversity for broad search terms</h3>
<p>Google uses AI to determine the subtopics behind a broad search term to provide diversity in search results.</p>
<p>For example, when someone searches for "home fitness equipment", the original (left in the picture below) will provide a relatively broad range of equipment recommendation articles, but after the change (right in the picture below), the search results will be more diverse, which may be "home fitness equipment for small spaces", "high-end home fitness equipment", "affordable home fitness equipment"... etc., making it easier for users to find results when the search intention is unclear.</p>

<h2 id="toc-3">Cloudflare launches website analysis and WP platform optimization tools</h2>
<p>Cloudflare has launched a website analysis tool that takes user privacy into consideration. This tool is free and can be installed by anyone. Because of privacy considerations, it is more like GA with many fewer dimensions. For example, "users" will not be recorded.</p>
<p>Another tool is Automatic Platform Optimizations (APO), which costs $5 per month. It first supports WordPress. Users only need to install the WP plug-in and register an account to enjoy this service. Different from ordinary CDN, because the Cloudflare plug-in is installed in WP, cloudflare will automatically cache the resources to the CDN when the web page is updated. In other words, even if the web page is visited for the first time, it does not need to go through the original server. The official figure is that it can reduce TTFB by 72%.</p>

<h2 id="toc-10">Google Search Podcast EP.7</h2>
<p>The focus of this podcast episode is that Gary talked about the operation of Caffeine (Google's indexing system). He briefly took notes and added his own interpretation, but I still recommend that you listen to it yourself when you have time.</p>
<figure class="embed embed--spotify"><iframe allow="autoplay; clipboard-write; encrypted-media; fullscreen; picture-in-picture" loading="lazy" src="https://open.spotify.com/embed/episode/2YNlwMWwJs1rJvULfQAae3" title="Spotify episode"></iframe><figcaption><a href="https://open.spotify.com/episode/2YNlwMWwJs1rJvULfQAae3" rel="noopener noreferrer">View original content on Spotify</a></figcaption></figure>
<ol><li>first in<a href="./how-search-engines-crawl.html">Googlebot crawls web pages
After</a>, it will spit out "<a href="https://developers.google.com/protocol-buffers">protocol buffers</a>"Then give it to Caffeine.</li><li>Next is conversion. Caffeine will normalize the information given by protocol buffers into a unified format (normalize). For example, the HTML of the web page may be missing a closing tag and strange tags appear in the &lt;head&gt;; or header tags may also be processed because the header tags on the web page may not represent their true importance on the page. Caffeine will standardize the data sent by Googlebot.</li><li>Of course, Google not only indexes web pages, but also PDFs, Docs, spreadsheets, etc., and different file types are standardized before they can be compared.</li><li>Caffeine will look at the meta tags in the file. There are some important instructions for search engines that must be followed, such as robots noindex tag.</li><li>There is also a thing called "Collapsor", its function is to handle "error pages". Sometimes non-existent pages will return 200. This situation is called soft 404s, and Collapsor is responsible for catching such situations.</li><li>Caffeine puts the organized information into the index.</li></ol>
<p class="has-light-gray-background-color has-background">In the fifth point, Gary talked about an interesting bug. If there is an article discussing error pages, Collapsor may judge the article as a soft 404 page because there are too many words like "page not found" that often appear on error pages on the web page, and Caffiene will stop processing the page.</p>
