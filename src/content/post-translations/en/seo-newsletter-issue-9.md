<h2>Non-AMP pages will be able to appear in Top Stories</h2>
<p>In the past, only AMP webpages could appear in the Top Stories section of search results. <h2>Lighthouse 6.0 released (added web vitals, score ratio reconfiguration...)</h2>

<h2>Bing’s new webmaster tool adds three new features</h2>
<p>Bing’s new webmaster tool adds the following three new functions, which are different from Google’s<strong>Crawl Limit (Crawl Control)
In the</strong>section, the webmaster can set to reduce the crawling frequency in a specific time period.</p>
<ul><li><strong>URL Submission Tool (URL Submission)</strong>- Actively submit URLs to Bing. Each account has a different daily limit.</li><li><strong>URL removal tool (Block URL)</strong>- Temporarily removes a URL from search results. Like Google, it is only valid for 90 days.</li><li><strong>Crawl Limit (Crawl Control)</strong>- Limit the crawler crawling frequency, and you can set the crawling speed at different times.</li></ul>

<h2>Bing Webmaster Tools built-in keyword planning tool</h2>
<p>I’m not sure if this feature is new, but there is a keyword planning tool in Bing Webmaster Tools, where you can enter a keyword and then see its exposure and trends, searches in each country, the top ten web pages ranking for this keyword, similar words, related questions, and newly emerged related keywords.</p>
<p>What I think is very special is that trends have accurate exposure numbers, which is just a relative index from 0 to 100 on Google Trends. In addition, the top ten web pages have a "Topics" category, which may represent what kind of "topics" the web pages have in Bing's eyes, which is quite interesting!</p>
