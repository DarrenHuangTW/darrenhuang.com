<h2 id="toc-2">[News] Bing content submission API is now available</h2>
<p>in<a href="./seo-newsletter-issue-5.html#toc-3">Issue 5</a>and<a href="./seo-newsletter-issue-13.html#toc-4">Issue 13</a>mentioned these two APIs of Bing, which allow webmasters to directly submit URLs or content to Bing so that they can be indexed in a timely manner. The URL submission API has been available for a while and has an official<a href="https://wordpress.org/plugins/bing-webmaster-tools/">WordPress plug-in</a>can be integrated; the content submission API will only be officially opened for full use in September this year.</p>
<div class="wp-block-image"><figure class="aligncenter size-full is-resized"><img alt="Illustration for SEO e-Newsletter Issue 40 – 2021.09.01~2021.09.15" class="wp-image-2998" decoding="async" height="257" loading="lazy" src="./wp-content/uploads/2021/09/Bing-%E7%B6%B2%E5%9D%80%E5%85%A7%E5%AE%B9%E6%8F%90%E4%BA%A4API.png" width="334"/><figcaption><a href="https://www.bing.com/webmasters/url-submission-api">official website</a></figcaption></figure></div>
<p>The main difference between the two is that the URL submission API submits the URL to Bing for crawling; while the content submission API puts the content in the API and submits it directly to Bing (theoretically, Bing does not even need to send a crawler to the web page).</p>
<p>A video of a previous interview with a Bing spokesperson<a href="./seo-newsletter-issue-19.html#toc-8">once said</a>, Bing wants to aim at helping webmasters actively submit new or updated content, because relying on crawlers to continuously discover new web pages and whether web content has changed in the online world (Googlebot's method) is too inefficient.</p>
<p>link:<a href="https://blogs.bing.com/webmaster/september-2021/Bing-Content-Submission-API-open-for-all-webmasters">official announcement</a></p>
