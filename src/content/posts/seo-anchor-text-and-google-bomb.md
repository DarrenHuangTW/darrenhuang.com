Backlink(反向連結)是Google用作排名網站的重要指標之一，而隨之而來的就是Anchor Text，Anchor Text不是甚麼很複雜的觀念，也(通常)不是可以人為操弄的一環，對一般的商家或網站擁有者而言這個觀念可能並不太重要，因為絕大說數情況下當網站自然的成長，在Anchor Text這一塊是不會有甚麼問題的。

這篇文章主要要從SEO的角度來看看Anchor Text，怎樣算健康怎樣算有問題，分享與Anchor Text有關的知識和趣事，文章內容都是一些看過就會的簡單東西，具備這些知識說不定也可以在未來保護你，看出與你簽約的網路行銷公司是否有用一些不太正當的手段。

<h2>甚麼是Anchor Text?</h2>
Anchor Text在中文叫做錨點文字，或大陸地區叫鏈接錨文本 or 錨文本。錨點文字就是可以點擊，然後點了會帶你到其他網頁的文字(或圖片)，Anchor Text伴隨著連結而來，通常是藍色然後有底線，舉例來說: <a href="./">首頁</a>。

從HTML的角度看Anchor Text:
<blockquote>&lt;a href="https://darrenhuang.com/"&gt;<b>首頁</b>&lt;/a&gt;</blockquote>
這裡的 https://darrenhuang.com/ 是我要連過去的網頁，然後&lt;a&gt; 和&lt;/a&gt;中間的文字<strong>(首頁)</strong>就是這個連結的 Anchor Text。
<h2>Anchor Text與SEO的關係</h2>
連結是整個網路架構的基礎，也是搜尋引擎決定排名的根據之一，如果你試著從Google的角度來看，<b>Google用Anchor Text來得知被連結的網頁大概在講甚麼東西是很合情合理的</b>。
<blockquote>ex. &nbsp;Himelight是我最近發現一個很棒的<a href="https://himelight.com/" target="_blank" rel="noopener noreferrer">履歷撰寫網站</a>。</blockquote>
上面這句話的Anchor Text是"履歷撰寫網站"，對不管是讀者或是搜尋引擎來說，都會期待這個連結點過去會看到的是一個....履歷撰寫網站。

回頭想想Google的宗旨，當一堆連到https://himelight.com/的連結都是說 "履歷撰寫"、"個人化履歷"、"如何寫出亮眼履歷"...之類的Anchor Text，Google可以很輕易的判斷出Himelight這個網頁，肯定和履歷有很大的關連，以後的人在搜尋"個人化履歷"相關字眼時，Himelight的網站就會比較容易出現!

<h2>Anchor Text的種類</h2>
Anchor Text對於Google理解你的網站有相當大的幫助，但是，一個網站對於別人連到自己網站時使用的Anchor Text很難有所控制，其中常見的幾種Anchor Text如下:
<h3>品牌名 / Brand Name</h3>
當公司或品牌名稱就是超連結的可點擊文字，是最常見的一種錨點文字。
<blockquote>ex:&nbsp;<a href="http://kkday.com/" target="_blank" rel="noopener noreferrer">KKday</a>是一個旅遊網站</blockquote>
<h3>網址 / "Naked" URLs</h3>
當Anchor Text本身就是被連結網站的網址。
<blockquote>ex: Matt Cutts的部落格網址是:&nbsp;<a href="https://www.mattcutts.com/blog/">https://www.mattcutts.com/blog/</a></blockquote>
<h3>沒啥幫助Anchor / Generic Anchor Text</h3>
這類型的Anchor Text也非常常見，大多是一些Call To Action，對於搜尋引擎判定被連結網站的內容的幫助很低。
<blockquote>ex: 我寫過一篇backlink的文章，<a href="./what-is-backlink-in-seo.html" target="_blank" rel="noopener noreferrer">請點此</a></blockquote>
<h3>圖片Anchor / Image</h3>
如果連結本身是個圖片 (點擊圖片會連到另一個網頁)，那麼Google很可能用該圖片Alt Tag的文字作為Anchor Text。
<blockquote>ex.

<a href="https://moz.com/rand/" target="_blank" rel="noopener noreferrer"><img class="aligncenter wp-image-194 size-full" src="./wp-content/uploads/2016/05/Rand-Fishkin-in-SearchLove-2016-Boston.jpg" alt="rand fishkin searchlove boston 2016" width="400" height="225" loading="lazy" decoding="async"></a></blockquote>
&lt;a href="https://moz.com/rand/"&gt;&lt;<b>img alt="Rand Fishkin"</b>&nbsp;src="XXX"/&gt;&lt;/a&gt;

其中，Rand Fishkin可被視為該連結的Anchor Text。
<h3>關鍵字型 / Keyword Match Anchor Text</h3>
<div>前面Himelight的例子就是屬於這一種，當Anchor Text就是和被連結站相關的關鍵字，在Google眼裡，該網站和該關鍵字之前的關聯就更為緊密。</div>
<blockquote>ex. &nbsp;Himelight是我最近發現一個很棒的<a href="https://himelight.com/" target="_blank" rel="noopener noreferrer">履歷撰寫網站</a>。</blockquote>
但是，只要是Google可能用來了解網站的Signals就會有SEOs試圖操弄。

<img class="aligncenter wp-image-199" src="./wp-content/uploads/2016/05/Exact-Match-Anchor-Text-Example.jpg" alt="exact match anchor text" width="550" height="331" loading="lazy" decoding="async">

如上圖的情況，很多連結的Anchor Text都是"SEO Consultant"，這個情況叫做Exact Match Anchor Text，當backlinks的Anchor Text有跟高比例都是同樣的關鍵字，那很大的可能是，這些連結都是該網站自己塞的，因為連結理當來自其他人自然提起你的網站，而<b>不可能每個人提起一個網站時都用同樣的關鍵字</b>。

每個連過來的Anchor Text都不太一樣，有SEO Consultant, SEO Specialist....但是Google又可以看出這個網站大概跟甚麼有關。

<h3>混和型 / Hybrid Text</h3>
混和型指的是品牌名稱加上關鍵字，通常被認為是最有效的Anchor Text。
<blockquote>ex. 我最近很常看<a href="http://www.simoahava.com/" target="_blank" rel="noopener noreferrer">Simo Ahava的Google Tag Manager文章</a>。</blockquote>
上面的Anchor Text包含了品牌名稱(人名)"Simo Ahava"還有關鍵字"Google Tag Manager"，可以更進一步加強兩者的關聯。

下面這個圖片非常有趣，在Google的建議搜尋出現品牌+關鍵字的結果，也許也或多或少是因為很多該網站的連結都是此種混和型Anchor Text。

<h2>Anchor Text 的正確觀念</h2>
如果你用了一些工具來分析網站反向連結的Anchor Text，結果發現其他人提到你的網站時，都是用 "<u>點擊此處</u>"、沒有Alt Tag的圖片、網址...等等，請記得<b>這是非常正常的現象</b>。

另外，Anchor Text只是佔了排名指標的小小小一個部分，我曾經看過人家說要試著連絡那些文章的作者請他們把Anchor Text改成更"SEO friendly"...，個人認為不用特別花時間心力去做這種事，如果整個文章的主題或上下文都和被連結網站有相當的關係，Google是可以輕易判別的!

(延伸閱讀: Co-Occurence&amp;Co-Citation )
<h2>錨點文字的趣聞 - Google Bomb</h2>
在2004年左右，當時的Google演算法還沒有這麼厲害可以判別人為與非人為的操弄，在美國的總統大選時，小布希遭到反對者的網路攻擊。

反對者們建立一堆連結連到白宮網站上小布希的網頁，這些連結的網站都用同一個字: "Miserable Failure"，過了幾個禮拜，在友人搜尋 Miserable Failure時，小布希的網頁就出現在搜尋結果的第一名，即使該網頁肯定沒有出現該關鍵字!

這個案件不是第一起也不是唯一一起的Google Bomb (Google炸彈)，但是應該是最有名的一則故事~
<h2>SEOs可以做些甚麼</h2>
Moz有一集的<a href="https://moz.com/blog/anchor-text-rich-links-without-spam-or-manipulation-whiteboard-friday" target="_blank" rel="noopener noreferrer">WBF</a>有提到幾個關於錨點文字 SEOs可以介入的地方，雖然Anchor Text不是也不該是可以被操弄的，但還是有一些小撇步可以盡量使他人連到你的網站時使用keyword-rich anchor text.

2. 寫信給記者或influencer推銷自己文章或內容時，不要直接講完一段話以後丟一個文章連結，取而代之的，可以試著給他們一句話然後選幾個關鍵字加上超連結，因為很多情況他們會直接複製貼上你說的話。
