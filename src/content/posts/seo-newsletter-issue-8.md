<h2>網頁UX指標三本柱 - LCP / FID / CLS </h2>



<p>網頁的用戶體驗一直以來都相當難量化，Chrome部門希望解決這一項痛點，選定了三項核心指標，並訂出各項指標的好壞標準，希望能將UX的衡量指標系統化。這三項指標分別為:</p>



<ul><li> Largest Contentful Paint (LCP): 衡量網站的速度</li><li>First Input Delay (FID): 衡量網站的互動性</li><li>Cumulative Layout Shift (CLS): 衡量網頁元件的視覺穩定性</li></ul>



<figure class="wp-block-image size-large"><img src="./wp-content/uploads/2020/05/UX%E4%B8%89%E5%A4%A7%E6%8C%87%E6%A8%99.jpg" alt="網站UX三大指標" class="wp-image-1165" loading="lazy" decoding="async" width="900" height="517"></figure>



<p>由Chrome所倡議的標準不容小覷，很多工具都相繼呼應將開始以這三項指標為軸，包括PageSpeed Insights, WebPageTest, CrUX, Lighthouse...等都宣布會在近期內開始支援，會在下面的篇幅再做介紹。</p>



<p>連結: <a href="https://blog.chromium.org/2020/05/introducing-web-vitals-essential-metrics.html">Chromium文章</a> / <a href="https://web.dev/vitals/">web.dev文章</a> / <a href="https://blog.amp.dev/2020/05/06/amp-web-vitals-a-better-web-together/">amp.dev文章</a> / <a href="https://www.ithome.com.tw/news/137434">(中文)iThome報導</a></p>

<h2>計算Web Vitals的Chrome插件</h2>

<h2>WebPageTest支援Web Vitals</h2>



<p>WebPageTest是在測試網頁速度時非常好用的一項工具，這項工具現在將Web Vitals作為報告裡的重要指標，同時也會在網頁載入的逐格影片中秀出Chrome所判定的LCP，並用紅色線條框起來。</p>


<blockquote class="embed embed--twitter"><p>Twitter／X 貼文</p><a href="https://twitter.com/patmeenan/status/1260294231589113859" rel="noopener noreferrer">在 Twitter／X 查看原始貼文</a></blockquote>


<p>註: FID沒辦法透過測試工具計算，因為工具並不會跟網頁有"互動"，所以用Lab Data一般會用Total Blocking Time (TBT)取代。TBT是另一個指標(web vital)，但並非Chrome Team所定義的核心指標(web core vital)。</p>

<h2>CrUX報告紀錄Web Vitals</h2>



<p>Chrome User Experience (CrUX)是一份公開的database，紀錄了Chrome用戶在瀏覽網頁時的網頁表現，相比於一般的測量工具的Lab Data，CrUX的資料屬於Field Data，相當珍貴。而這項公開資料也開始記錄三項web core vitals，可以利用Google BigQuery跑出來，以下為104人力銀行網站的結果。</p>



<figure class="wp-block-image size-large"><img src="./wp-content/uploads/2020/05/104%E4%BA%BA%E5%8A%9B%E9%8A%80%E8%A1%8C%E7%B6%B2%E7%AB%99%E7%94%A8%E6%88%B6%E9%AB%94%E9%A9%97-1024x665.png" alt="" class="wp-image-1172" loading="lazy" decoding="async" width="1024" height="665"></figure>



<p>上述的資料可以解讀為：92.08%的使用者在瀏覽104人力銀行網站(www.104.com.tw)時的LCP載入時間是好的(&lt;2500ms)，4.97%普通(&gt;=2500ms, &lt;4000ms)，2.91%不好(&gt;=4000ms)，其中第75個百分位數的LCP為1400ms。</p>



<p>連結: <a href="https://github.com/GoogleChrome/CrUX/blob/master/sql/core-web-vitals.sql">跑出上圖結果的Query</a></p>
