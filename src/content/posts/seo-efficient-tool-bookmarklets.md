成為一個SEO從業人員後，三不五時就需要去看看Source Code、使用"site:", "cache:"之類的指令為網站做健診，這些步驟也許不是特別花時間，但是如果有個工具可以讓你一點就可以檢查某個網頁每張圖的Alt Tag、一點就可以看到該網頁cache的樣子、甚至一點就可以讓你看到該頁面的Title, Description, 還有其他Meta Tags，絕對是省下很多時間! 這篇文章要分享幾個我頗常用也滿喜歡的Bookmarklets，希望能對SEOs們有所幫助!
<div></div>
<h2>什麼是Bookmarklet?</h2>
Bookmarklet的中文叫做小書籤，和一般的書籤不一樣的地方是，<b>它是一串JaveScript而不是一個URL</b>。舉例來說，工程師們可以寫一個指令: 告訴我當前網頁的rel canonical tag是什麼，把這個指令放進瀏覽器的書籤列後，以後要檢查網站時就只要點一下該小書籤，就會直接告訴你答案了!
<h2>使用方法</h2>
小書籤的好處就是使用起來超級簡單，就算自身不會coding，只要找到有人分享(像這篇文章)，把連結拖到書籤列就可以方便以後使用了。

<h2>10個SEOs常用小書籤</h2>
下面列出幾個我個人最常用的功能，包括檢查當前頁面的meta robots tag, canonical tag，Wayback Machine，Google Page Speed Insights，開啟Open Site Explorer...等，屁話不多說，一起動手來試試看吧!
<h3>1. 檢查當前網站有多少頁被index</h3>
<blockquote>Bookmarklet: <a>Site Search(site:+domain)</a></blockquote>
在Google輸入site:www.example.com來找出某網站有多少網頁被Google索引，這個指令對多數SEOs絕對非常熟悉，而這個小書籤讓你不管在該網站的哪一個網頁，都可以一點就搜尋Site+domain而不用複製貼上來來去去。

<img class="aligncenter wp-image-136 size-full" src="./wp-content/uploads/2016/06/site-operator.jpg" alt="site search operator" width="798" height="249" loading="lazy" decoding="async">
<h3>2. &nbsp;檢查當前網頁是否被index</h3>
<blockquote>Bookmarklet: <a>Info Search(site:+current page)</a></blockquote>
這個是我本篇要介紹的小書籤裡面唯一一個自己寫的XD 主要用來檢查當前的頁面是否已經被Google Index。假設你現在在<a href="https://moz.com/blog">https://moz.com/blog</a>，用這個書籤可以讓你看到該頁是否已被索引，而不會出現/blog下的其他頁面。

<img class="aligncenter wp-image-137 size-full" src="./wp-content/uploads/2016/06/info-operator.jpg" alt="info operator" width="804" height="268" loading="lazy" decoding="async">

&nbsp;
<h3>3. 檢查當前網頁的Cache版本</h3>
<blockquote>Bookmarklet:&nbsp;<a>Google Cache</a></blockquote>
Crawl / Index / Cache之間的概念就不再多敘述咧，簡單來說這個小書籤可以讓你看到當前網頁在Google的眼裡是長甚麼樣子，在網頁內容有更動後，你可能會常常使用它來看看Google是否已察覺到這個改變。

<img class="aligncenter wp-image-138 size-full" src="./wp-content/uploads/2016/06/google-cache-version.jpg" alt="google cache" width="1267" height="114" loading="lazy" decoding="async">

&nbsp;
<h3>4. 開啟Open Site Explorer檢查當前網頁</h3>
<blockquote>Bookmarklet: <a>用OSE查看當前網頁資料</a></blockquote>
之前寫過一篇關於<a href="./seo-backlinks-tool-open-site-explorer-ose.html" target="_blank" rel="noopener noreferrer">Moz的這個工具Open Site Explorer</a>，利用此小書籤可以直接開啟OSE然後看看現在所在頁面的一些基本資料(DA/PA, inbound links...等等)，對有Moz Pro的人來說非常好用!

<h3>5. 檢查當前頁面的Canonical Tag</h3>
<blockquote>Bookmarklet: <a>Check the canonical tag</a></blockquote>
一點就會跳出一個小框框告訴你目前所在頁面有沒有rel canonical tag，有的話是canonicalize到哪裡去， &lt; link href="https://darrenhuang.com/" rel="canonical" /&gt;。

<img class="aligncenter wp-image-140 size-full" src="./wp-content/uploads/2016/06/check-canonical-tag.jpg" alt="check canonical tag" width="503" height="195" loading="lazy" decoding="async">

&nbsp;
<h3>6. 檢查當前網頁的meta robots tag</h3>
<blockquote>Bookmarklet: <a>Check meta robots tag</a></blockquote>
這個小書籤會檢查當前網站的meta robots tag，會跳出一個框框和你說robots meta tag裡面是否有index/noindex, follow/nofollow, noodp, noydir, nocache, noarchive....等等指令。

<img class="aligncenter wp-image-142 size-full" src="./wp-content/uploads/2016/06/check-meta-robots-tag.jpg" alt="check meta robots tag" width="484" height="188" loading="lazy" decoding="async">

&nbsp;
<h3>7. 用Wayback Machine看看當前網頁以前長得怎樣</h3>
<blockquote>Bookmarklet: <a>Wayback Machine</a></blockquote>
Wayback Machine是可以看到一個網頁以前的模樣*，這個小書籤可以讓你一鍵進到Wayback Machine分析完目前網頁的結果，然後選日期看看該網頁在不同時期的樣子。
(*註: 不是每個網頁都會被存取的!)

<h3>8. 檢查當前網頁的Page Speed Insights</h3>
<blockquote>Bookmarklet: <a>Google Page Speed Insights</a></blockquote>
有點經驗的人對這個工具應該不陌生，可以分析網頁的讀取速度，而此小書籤讓你不用又開新分頁又搜尋又複製貼上，一鍵搞定!

<h3>9. 秀出該網頁所有圖片的Alt Tag</h3>
<blockquote>Bookmarklet: <a>Show All Alt Tag</a></blockquote>
點一下就會跑出該網頁所有圖檔以及他們的Alt Tag，方便快速檢查是否有重要圖片忘記加上妥當的關鍵字。

(有個缺點是它的格式頗醜，有時候還要往旁邊拉才能看到Alt Tag的欄位，如果有JavaSript高手知道如何調整歡迎分享!我會很願意更新這篇的資訊。)
