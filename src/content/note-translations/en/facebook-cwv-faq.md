This post summarizes several key points from Google’s official Q&amp;A before Core Web Vitals officially becomes the focus of search-related discussions in 2021.

The Q&amp;A at the time stated that LCP, FID and CLS were measured separately, and that the page experience data would be based on actual user data over a period of time.

It also reminds webmasters that Core Web Vitals are part of the ranking signal, but that all SEO efforts should not be reduced to chasing PageSpeed ​​scores.

The indicator names and search environments in this note belong to the historical context of 2021.

To diagnose a website today, it should be read alongside current Web Vitals metrics, CrUX data, and real user experience.
