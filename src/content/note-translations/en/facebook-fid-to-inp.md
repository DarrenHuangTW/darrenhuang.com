This 2023 post documents the background to Core Web Vitals' move from FID to INP.

INP focuses on how long it takes for a page to generate a visible response after a user clicks, touches, or uses the keyboard.

This concept is closer to the interaction latency experienced by the user throughout the browsing experience than an FID that only observes specific interactions.

The original post used the shopping cart, mobile navigation menu and login form as examples to explain why "no response after operation" can make users mistakenly think that the website is broken.

This page is for historical preservation and conceptual organization, not an operation guide for today’s Core Web Vitals.

If you want to implement or interpret the threshold, you should still refer to the current Chrome, CrUX, PageSpeed ​​Insights and Google official documents.
