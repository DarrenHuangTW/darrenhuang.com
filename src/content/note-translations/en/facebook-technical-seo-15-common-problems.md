This post compiles a list of common technical SEO questions for 2023.

The list includes issues such as 3XX redirects, HTTP to HTTPS redirects, missing alt attributes for images, missing or too long meta descriptions, page speed, inconsistent titles and search results, insufficient internal links, missing or duplicate H1s, and incomplete Open Graph tags.

The raw statistics are a snapshot of the data at that time and should not be taken directly as a proportion of all websites today.

What’s worth preserving long-term is not the percentage, but the order of checks: first make sure that users and search engines can get the correct content, and then handle indexing, internal links, excerpts, and social sharing presentation.

A technical SEO checklist shouldn’t turn into an endless box-ticking exercise, either.

Every question should go back to the purpose of the page, user friction, and business value to determine whether the revision will actually improve usability, understandability, or discoverability.
