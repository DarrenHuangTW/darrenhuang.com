This post explains Search Console's crawl statistics, paying special attention to whether crawlers are re-scrubbing old pages or discovering new pages.

If you have a site that frequently adds new content and most searches are focused on older pages, you may want to check whether internal links and sitemaps are making it difficult for new content to be discovered.

Conversely, if a site doesn't add a lot of new content but experiences a very high discovery rate, it's also worth checking whether the filter is generating a lot of duplicate URLs, or if the site is being populated with unusual pages.

This perspective can turn "Did Google crawl the website" into a more specific diagnostic question.

The original interface and report names belong to the background of 2021. When using it today, you should compare it with the official documents based on the current Search Console fields.
