這則早期貼文記錄一個搜尋結果摘要的觀察案例。

頁面在搜尋結果中出現了看起來像作者資訊的文字，但頁面正文並沒有完全相同的句子，因此當時推測 Google 可能從頁面不同區塊拼湊摘要來測試使用者反應。

這提醒我們，meta description 是重要的建議訊號，但不一定能強制搜尋引擎在每次搜尋中原樣顯示。

比較穩健的做法，是讓 meta description 準確概括頁面內容，同時確保標題、正文、結構化資料與作者資訊彼此一致。

這是 2018 年的個案記錄，不應被理解成今日搜尋摘要系統的完整規則。
