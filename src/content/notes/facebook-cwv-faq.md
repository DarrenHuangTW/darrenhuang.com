這則貼文整理 2021 年 Core Web Vitals 正式成為搜尋相關討論焦點前，Google 官方問答中的幾個重點。

當時的問答說明 LCP、FID 與 CLS 是分開衡量的指標，頁面體驗資料則會以一段期間內使用者的實際資料作為基礎。

它也提醒網站管理員，Core Web Vitals 是排名訊號的一部分，但不應該把所有 SEO 成效都簡化成追逐 PageSpeed 分數。

這篇筆記中的指標名稱與搜尋環境都屬於 2021 年的歷史脈絡。

今日若要診斷網站，應該把它和目前的 Web Vitals 指標、CrUX 資料與真實使用者體驗一起閱讀。
